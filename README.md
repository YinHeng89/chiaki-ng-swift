# chiaki-ng-swift

![chiaki](https://raw.githubusercontent.com/chiaki-ng/chiaki-ng/8179a2d1964c75dc32614fd27e51c2381093f539/gui/res/chiaking-logo.svg)


## Requirements

- macOS 26 or newer on Apple silicon
- Xcode 27 with the macOS 27 SDK
- Homebrew
- Git SSH access to the core submodule's repository (see `.gitmodules`)
